WindowVM · Windows 11 ARM

这是自用原型。系统安装、Windows 内浏览器上网及中英文剪贴板，需要安装真实 Windows 后完成验收。目前不承诺取代成熟虚拟机产品。

安装 Windows

  1. 从 微软官方下载 Windows 11 ARM64 ISO。不要下载 x64。下载后可按微软页面提供的 SHA-256 校验。
  2. 下载 VirtIO 驱动 ISO，在应用中选择两张镜像。需要驱动 ISO 内包含 Windows 11 的 ARM64 网卡驱动；如果只有 amd64，不能使用，请核对新版驱动。
  3. 点击“创建并安装 Windows”。首次分配 80 GB 稀疏磁盘，实际占用按使用增长。屏幕出现在独立 QEMU 窗口。若提示 Press any key to boot from CD，请及时按任意键。
  4. 按 Windows 向导安装到 NVMe 磁盘。此方案附带 TPM 2.0 和预注册微软证书的安全启动固件；若安装程序仍报告硬件不满足要求，保留提示并反馈，不要使用不明来源的绕过镜像。
  5. 安装需要联网时，使用“安装驱动程序”选择驱动光盘中 NetKVM\w11\ARM64（目录以镜像实际内容为准）。如果当前安装界面没有驱动入口，可按 Shift+F10，执行 pnputil /add-driver E:\NetKVM\w11\ARM64\*.inf /install，其中 E: 换成驱动光盘实际盘符。
  6. Windows 安装完成并关机后，取消“挂载安装镜像”，再启动，避免重新进入安装程序。Windows 授权和激活使用你自己的有效许可。

如果使用本机准备的 WINDOWVM_NET 驱动光盘，网络驱动位于光盘根目录，选择该光盘即可。完整 VirtIO ISO 的路径仍按上面的 NetKVM 目录选择。

共享剪贴板

在资源管理器打开 WINDOWVM_TOOLS 光盘，双击 Install.cmd。安装到当前用户，无需管理员；支持双向纯文本和中文，不支持图片、文件及格式。配套程序通过仅监听 Mac 本机的 HTTP 端口 47831 和随机令牌连接；不会把服务开放给局域网。同步期间两边复制的文本会互相可见。

关闭应用中的共享剪贴板需先关机。卸载配套程序：Win+R 输入 shell:startup，删除 WindowVM Clipboard 快捷方式，注销 Windows 后删除 %LOCALAPPDATA%\WindowVM。

窗口大小与分辨率

拖动虚拟机窗口任意边角即可改变大小。连续拖动时每 800ms 最多更新一次 Windows 实际分辨率，结束后补齐最终尺寸；支持 640×480 至 3840×2160。Retina 屏幕按物理像素渲染；例如 1280×800 窗口对应 2560×1600 分辨率。请在 Windows 设置 → 系统 → 屏幕将缩放设为 200%，保持文字大小。普通 1× 屏幕使用 100%。首次使用：在 WINDOWVM_TOOLS 光盘运行 InstallDisplay.cmd 安装签名 ARM64 显示驱动，再以普通用户运行 Install.cmd 更新配套程序并重启 Windows。之后登录即自动适配。剪贴板开关不影响显示适配。

网络互通

  • Windows 默认通过 NAT 上网。访问 Mac：http://10.0.2.2:端口。Mac 服务需要 IPv4 监听，Mac 的 localhost 在 Windows 中不能直接使用。
  • Mac 访问 Windows：默认 http://127.0.0.1:18080 转发到 Windows 的 8080 端口。Windows 服务需监听虚拟网卡或 0.0.0.0，并允许对应防火墙规则。应用支持关机后修改两侧端口。
  • NAT 不等于桥接：Windows 没有独立局域网地址；局域网广播发现、VPN 路由和企业代理需要实际联调。端口冲突会阻止启动，请查看日志并修改端口。

宿主系统代理

Windows 默认不会继承 Mac 代理。在 WINDOWVM_TOOLS 光盘运行 UseHostProxy.cmd，测试 HTTPS 通过后，将本次启动读取的 Mac HTTP/HTTPS 系统代理设置到当前 Windows 用户。Mac 的 localhost 映射为 10.0.2.2，无需“允许局域网”或修改宿主监听。浏览器和支持系统代理的应用会使用它；其他应用需自行配置。RestoreProxy.cmd 恢复原值。宿主代理端口变化后，重启虚拟机并重新运行此脚本。暂不转换 PAC 或仅 SOCKS 代理。

暂停与继续

关闭 WindowVM Engine 窗口或退出 Engine，会保存 Windows 内存和设备状态，完成后自动关闭窗口并释放内存。管理界面也有“保存并暂停”。再次打开 WindowVM 或 Engine 会自动继续；也可以点击“继续 Windows”。退出运行中的管理应用同样会先保存。真正关机使用“正常关机”或 Windows 开始菜单。

保存期间请等待窗口自行消失，不要强制退出。保存文件可能接近配置的内存大小。暂停期间不能调整 CPU、内存或挂载镜像，也不要修改磁盘、TPM、固件和工具光盘。升级引擎、swtpm 或移动应用前先继续并正常关机。状态不匹配会保留文件并提示，不会改为冷启动。暂停是一次性继续状态，不是历史快照；恢复后的旧网络连接可能需要刷新。

运行与数据

优先在 Windows 开始菜单里关机，也可以使用应用“正常关机”。“强制停止”可能丢失未保存数据；关闭 Engine 窗口会先保存并暂停。Windows 桌面使用 VirtIO GPU，固件保留 framebuffer 回退；没有 3D 加速、音频和文件共享，网页视频性能需实测。

数据位于 ~/Library/Application Support/WindowVM/Windows11，包括 qcow2 磁盘、UEFI 变量、TPM 状态和日志。备份时必须完全关机，并一起备份整个目录；不要只复制系统磁盘。不要删除 TPM 状态。程序不会读取或修改 Parallels 虚拟机。
